## What this does and does not show

- It shows the server rules and the v3 prompt handle these 73 phrasings on today's
  `gpt-4.1-mini` deterministically enough (temperature 0) to be correct on every labelled field.
- It does **not** show general accuracy: the dataset is small, written by the engineer who changed
  the code (overfitting risk), single-labelled, and every case ran once. The `evaluation.md` §6
  thresholds ask for ≥ 120 text cases with vi / en parity, a second labeller and repeated runs.
- Not covered here: photos (receipts, notes), voice-typed text with heavy typos, follow-up
  _questions_ ("còn hôm qua?"), long multi-intent batches (> 3 items), other currencies than
  VND / USD / EUR, other locales than Vietnam's zone, reminders across a month / year boundary.
- Re-run on every prompt or model change; keep every past failure in the dataset.

How to run: `docs/assistant/evaluation.md` §5 (the command is in the harness header).

## 2026-10-16 — timers, observations vs logs, repeats, review fields (live, dev model)

Owner-approved live run after the device reports of 2026-10-16 (api.md "Timers and review
fields"). Same harness, emulator and synthetic data as above; prompt `assistant-extract-v4`
(`phase`, "a plain state is never an observation"); key from Secret Manager into the run's
environment only, never printed. Short private `TMPDIR` (the scratchpad path is too long for tsx's
IPC socket).

**Dataset** +24 cases (97 in all): `tmr-01…13` ongoing states and timers (start now / at a said
time, already running → TIMER_RUNNING + stop offer, stop of a running sleep / feed timer, "dậy rồi"
with no timer → start question, en), `obs-02…05` observation vs log ("bé ngủ 2 tiếng" is a sleep,
"bé vừa bú mẹ 15 phút" a feed; "bú ít hơn mọi khi", "quấy hơn mọi khi" stay observations),
`rep-01…02` the same message again (SAME_AS_PENDING, 0 credits, no model call, nothing replaced),

report "Con đã bú mẹ được 20p" + "Vừa xong"). Harness: timer fields (`timer`, `action`, `tAt`),
`missing` (exact list), `noReview` (state `draft`, nothing flagged), `codes`, seeds `sleepTimer` /
