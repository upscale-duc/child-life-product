# S2 — Identity & onboarding (in progress)

**Status:** the email path works end to end on iOS and Android against the dev backend code (local emulators): splash → welcome → tour → sign-in → email account → verify prompt → "Bạn là ai với bé?" → baby profile → trackers → `createBabyProfile` → first-run Today. Backend is deployed to `child-life-dev`. **Not done:** Google sign-in waits for the provider to be enabled in the Firebase console; Sign in with Apple and universal links wait for an Apple Developer team; the avatar photo path is tested server-side but not yet on a device. Checklist rows are ◐, never ✓.

## Built

- **Backend** (deployed to dev)
  - Contracts `packages/contracts/src/baby.ts`: trackers, gender, relations, IANA time zones, `createBabyRequest`, avatar requests, 3-baby cap.
  - Callables in `firebase/functions/src/babies.ts`:
    - `createBabyProfile`: one transaction creates the family on the first baby (P-001), the baby, the restricted profile (DOB, gender), the owner membership and the account doc. It is idempotent per request id, enforces the cap (R-043) and checks the DOB against "today" in the baby's own zone.
    - `setBabyAvatarImage` / `getBabyAvatarImage`: JPEG only, ≤ 1 MB, Cùng nuôi to change, any active member to read. Storage stays closed to clients.
  - Firestore Rules for users, families, babies, the restricted profile (Cùng nuôi + relatives with `viewBabyInfo`) and memberships, plus a collection-group index for "my babies".
  - Auth on Identity Platform (D-014): email/password, 8-character minimum, email privacy on.
- **App** (`apps/mobile`)
  - Screens 00 splash, 01 welcome, 02–05 tour, 06 sign-in (custom Apple button, D-016), 07 email, 08 verify (D-015, "Bỏ qua"), 09 forgot password, 10 email already used, 10a, 11 with sheets 11a / 11b / 11c, 12, 13 appearance and 13a Night care schedule, and a first-run Today shell (18, no logging yet).
  - Session-driven routing (`app/route_guard.dart`, pure and unit-tested).
  - vi + en strings (173 new ids, `tool/s2_strings.py`).
  - Native config: camera / photos permission strings (vi, en); Android queries for the mail app, Custom Tabs and the camera.
  - `--dart-define=CL_EMULATORS=true` for local end-to-end runs; prod builds refuse it.
