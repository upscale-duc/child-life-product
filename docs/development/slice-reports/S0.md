# Slice S0 report — repository, environments, CI

Date: 2026-10-10 · Environment: **dev only** (`child-life-dev`, asia-southeast1). Prod does not exist yet (D-005).

## What changed

- **Monorepo** per implementation plan §3.1: pnpm workspace (`apps/landing`, `apps/portal`, `packages/contracts`, `packages/web-config`, `packages/vite-robots`, `firebase/functions`, `firebase/tests`, `scripts`) and Flutter app `apps/mobile`. Toolchain pins: Node 22, pnpm 11.20, TypeScript 6.0.3, Flutter 3.44.8.
- **Dev project provisioned:** APIs, Firestore `(default)` and default Storage bucket in asia-southeast1 (public access prevention on), iOS / Android / 2 web apps registered, Hosting sites `child-life-dev-landing` / `-admin`.
- **Rules:** deny-by-default Firestore and Storage Rules deployed; only `publicConfig/{flags|limits}` is readable (get only).
- **Functions** (2nd gen, Node 22, asia-southeast1): `ping` (round trip that refuses a client from the other environment) and `mirrorPublicConfig` (validates `config/*` with the shared Zod schemas before publishing to `publicConfig/*`). esbuild bundle so workspace packages never reach Cloud Build.
- **Flag & limits store** (P-122, D-010, D-011): schemas and defaults in `packages/contracts`; dev seeded with `scripts/src/seed-config.ts`, which refuses any project but `child-life-dev`.
- **Mobile:** flavors `dev` / `prod` (Android product flavors; iOS configurations + schemes generated by `tool/ios_flavors.rb`), app ids `app.childlife.dev` / `app.childlife`, minimum iOS 16.1 / Android API 26, environment resolver that refuses mixed or missing config, Firebase init, Crashlytics (Flutter + platform errors, dSYM upload phase for non-Debug iOS builds), Performance, Riverpod + go_router shell, temporary diagnostics screen.
- **Multi-language (D-012):** Flutter gen-l10n with Vietnamese template + English; web react-intl catalogs vi/en with a language picker on the landing; device/browser language with Vietnamese fallback; Android per-app language config; iOS `CFBundleLocalizations`.
- **Web:** landing and portal skeletons with environment + host checks, `noindex` and `Disallow: /` on dev, security headers; portal calls `ping`.
- **CI:** `.github/workflows/ci.yml` (format, typecheck, lint, unit tests, Rules tests on emulators, Functions bundle, web builds, Flutter analyze/test/APK, iOS simulator build, gitleaks). Not yet run on GitHub — the repository has no remote.
- **Docs:** README, CLAUDE.md, ADR-001 (architecture), ADR-002 (region), ADR-003 (environments); decisions D-006 … D-012 recorded in the business map.
