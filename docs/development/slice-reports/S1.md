# Slice S1 report — design system & app shell

Date: 2026-10-10 · Environment: dev. Figma sources: Foundations `17:467`, Components `7:4`, Logo `33:2`, **Motion spec `269:19`** (added by the owner during the slice), Splash `36:2233`.

## What changed

- **Token pipeline:** `packages/design-tokens/tokens.json` is the single source (34 colours × Light / Night care, 6 care categories incl. pump, type scale + `title-2`, spacing, radius, shadows, Figma motion tokens). `pnpm --filter @child-life/design-tokens run build` generates `apps/mobile/lib/core/design/tokens.g.dart` (dart-formatted) and `dist/tokens.css`; `run check` fails CI when outputs are stale.
- **Theme:** `ClTheme` extension (`context.cl.colors / care / shadows / text`), Light and Night care `ThemeData`, cross-fade between palettes (motion.gentle), platform-default screen transitions with a Reduce-Motion fade (D-013).
- **Typography:** Be Vietnam Pro 400/500/600 bundled (OFL); `ClTabularText` keeps digits steady because the font has no `tnum` (P-064).
- **Motion (Figma Motion spec):** `ClMotion` tokens, spring for `standard` (iOS response 0.35 / damping 0.86; Android stiffness 380), press 0.96, disabled 40 %, scrim 0 → 32 %, stagger helper; Night care = no bounce / shorter / no haptics except success; Reduce Motion = fades. Haptics: light tap, success, warning.
- **Appearance:** Sáng / Tối / Tự động, Night care schedule (default 21:00–06:00, crosses midnight), auto Night care while a timer runs; stored per device (P-061); minute-boundary clock (no per-second rebuilds).
- **Components (40+):** buttons, round / back, chips, sync status, error banner, float chip, avatar, segmented (sliding thumb), card groups, list / detail / option / info / setting rows, radio, toggle, text field (focus ring, password eye), code input (6 digits), amount field, time row, filter / relation chips, day pill, choice / select / permission tiles, role option, entry option (per care category), NavBar per role with animated active pill, TabDock, QuickLogButton (hidden for relatives), NavHeader, TopBar variants, progress, page dots, baby switcher, custom bottom-sheet route (spring open, exit close, 30 % drag / flick dismiss), toast with undo (24 px slide, 4 s), skeleton shimmer, empty state, coachmark, tour tip, member / account rows, theme option, icons (39 SVG), illustrations (22 SVG), logo.
- **Branding:** iOS app icons per flavor with Light / Tinted appearances (D-047: the Light icon also in dark mode; dev uses the same Light icon and is told apart by its name); Android adaptive icons per flavor; native launch screens (iOS storyboard, Android 12+ splash API, light + night).
- **Showcase:** dev-only `/showcase` with live Light / Night care and vi / en switches.
- **i18n:** component accessibility labels and tab names in vi + en ARB.
- **CI:** token check; goldens run on the macOS job; unit / widget tests on Ubuntu.
