## Built

### Backend (deployed to dev)

- **Timers:** `babies/{b}/timers/{sleep|breast|pump}`, one per baby and type (P-011).
  - The first start owns the slot. A second device's start is refused by the Rules, and that device follows the running timer ("Cả nhà đang thấy").
  - Updates can change the start time, sides and pause only.
- **Ending a timer** writes the record `r_<session>` and frees the slot in one atomic write, so it creates exactly one record.
- **Records:**
  - sleep records need an end time and last at most 24 h;
  - breastfeeds from the timer carry per-side minutes and the side they ended on.
- **Overlap:**
  - `onCareRecordWrite` opens a conflict when two live sleeps overlap, and closes it once they no longer do.
  - `resolveSleepOverlap` keeps one sleep and bins the other. A caregiver can only bin their own (D-022).

### App

- **Timers:**
  - 25 sleep timer: breathing ring, "Sửa giờ bắt đầu", cancel with confirmation;
  - 23b breastfeed timer: tap to switch side, pause / resume, total = sum of the sides, "Lần trước kết thúc bên …";
