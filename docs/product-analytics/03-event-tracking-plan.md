# Versioned event tracking plan

**Spec trước implementation.** Reuse existing contracts/producers; không analytics SDK mới, không viết lại notification system. IAP/billing events giữ nguyên existing behavior nếu có, nhưng **không xây purchase/trial/revenue tracking trong scope này**. Canonical ENG events giữ từ [ENG dictionary](../product-audit/14-notification-implementation-plan.md#analytics-contract--hoàn-thiện-trước-engine).

## Hai boundaries, không trộn raw identifiers vào general analytics

1. **Operational observation intake private:** authenticated callable/domain trigger kiểm quyền, dedup source transitions, có receipts/cohort joins theo [architecture](06-data-architecture.md). Ref opaque chỉ trong private authorized scope, local asset/PhotoKit IDs không lên server. Dùng business source mà server đã biết khi xác minh actor/completion, không đưa child payload vào generic analytics.
2. **Aggregate product metrics:** closed event/dimension enums và counts/version/period; không user/family/baby IDs, source refs, tokens, raw URI, text, photos, DOB, exact historical capture/milestone dates. Portal chỉ nhận aggregate. Pseudonymous IDs cũng không là anonymous.

Đề xuất private observation schema v1: `schemaVersion`, canonical `eventName`, opaque `receiptId`, `occurredAt`, server `receivedAt`, server-authorized `unitRef`/`sourceGeneration` khi có, `producerVersion`, fixed dimensions. Source local có opaque local episode key trong UID store; register/validate để đổi sang server unit ref khi online. Không cần đưa asset list lên server. Không coi client clock là authority cho care due, expiry hay global budget.

Aggregate envelope: `metricVersion`, `eventName`, reporting date R, validated stage/outcome/reason, approved dimensions, integer counts. Count retry events riêng attempts, unit stage once. Raw client n-counts cũ không tự trở thành dedup cohort events.

## Dimensions và identity rules

| Dimension               | Values / origin                                                       | Constraint                                                                                                                                                       |
| ----------------------- | --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| platform                | ios/android/unknown, source device at activity                        | Không dùng platforms-ever để lọc dated activity; cross-device U/F overlap, totals exact union                                                                    |
| locale                  | vi/en/other/unknown at observation; cohort locale frozen at entry     | Filter UI language độc lập app-locale filter; đổi locale không cohort mới                                                                                        |
| module                  | care/grow/remember/family/lumi/personalization/engagement             | Fixed map từ confirmed domain action; content topic/health category không dimension                                                                              |
| role class              | creator/caregiver/viewer/unknown, authoritative permission snapshot   | Không suy người thân luôn upload được; permission revoked cancel source opportunity                                                                              |
| Chapter                 | approved Chapter ID+mappingVersion hoặc unknown                       | Age stage không tự là Chapter; không mở Chapter 02–04 functionality                                                                                              |
| onboarding age band     | PA-03 bands versioned server-derived từ DOB restricted                | Chỉ coarse band xuất aggregate; account primary-context freeze, không exact age/DOB                                                                              |
| context                 | current/retrospective/not_applicable/unknown                          | Historical import/backfill tách; retrospective không outbound outdated milestone                                                                                 |
| source mode             | fresh/pending/cloud/import/none/unknown, giữ canonical ENG enum       | Native scan vs manual/historical origin có field `originClass` riêng scan/manual_import/cloud/current_record/historical_import/unknown; không thay enum ENG ngầm |
| ENG kind/channel        | ENG-00..06; in_app/local/push/digest/none/unknown                     | Scheduled/provider accepted ≠ delivery                                                                                                                           |
| template                | published catalog template ID+version, server validate                | Không user-supplied template names/captions, cardinality budget/other bucket                                                                                     |
| model/operation         | server-returned model allowlist + fixed operation/prompt/rate version | No prompt/conversation; provider failed paid calls included if usage exists                                                                                      |
| decision/outcome/reason | Canonical ENG decision enums + source/error enums                     | No free-text errors; unknown schema/dim reject                                                                                                                   |
| commercial plan         | **Backlog**                                                           | Không collect/gate UI/filter theo Free/Plus/Pro trong V1 analytics                                                                                               |

Identity membership joins dùng event-time active permissions. Một U nhiều devices dedup user-day; một F nhiều caregivers/babies dedup family-day/outcome. Actor attribution chỉ khi chứng minh từ operational writer/action; legacy missing actor = unknown, không gán owner. User merge/guest→registered cần canonical alias migration private hoặc mark unavailable, không đếm registration lần hai.

## Offline, replay, late clients và coverage

- New private observation callable versioned separately from legacy `{event,n,dim}`. Reject malformed/unknown dimensions and raw payload fields, rate-limit abuse, server-only events deny client. Aggregate output never accepts client-declared conversions.
- UID-scoped durable observation queue local; bounded retention/batch, cancellation on logout/revoke, no upload of previous account’s queue under next user. Device-native pending review retains local asset mapping only.
- Duplicate/replayed observation uses same receipt key; parallel devices still one logical stage. Provider API retries are real attempt units, not duplicate logical conversions. Existing non-idempotent counters remain legacy, not retroactively deduped without evidence.
- occurredAt/client clock untrusted: validate skew/observed evidence, server receivedAt always present. Late≤72h proposed repair affected partitions; older valid late sources correction version/unknown coverage, not silent discard or invented exact date. Source capture date never backdates actual app use.
- Legacy clients lacking events still use existing features. Report coverage by producer version; missing discovery/open/actor is `unknown`, not false/inactive/completed. Historical instrumentation start dates in API prevents fabricated past cohorts.
- Retention/deletion aligned [06](06-data-architecture.md): no extending ENG source retention merely to build arbitrary user tracking. Tests required for each producer mapping, retry, source revoke, no-PII schema, offline order and fixture→aggregate→Portal reconciliation.
