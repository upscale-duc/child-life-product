## Quy ước kiểm chứng

| Trạng thái bắt buộc        | Cách dùng trong audit                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------- |
| Implemented and verified   | Có code được đọc và kiểm thử liên quan chạy lại đạt; chỉ xác nhận trong biên kiểm thử mô tả |
| Implemented but incomplete | Luồng chính có thật, có khoảng hở xác định                                                  |
| Partially implemented      | Chỉ một phần khả năng mong muốn được tìm thấy                                               |
| Planned/documented only    | Có tài liệu/marketing, chưa thấy implementation tương ứng                                   |
| Not found                  | Không tìm thấy sau khi đọc entry points, module, contracts và tìm theo tên/synonym          |
| Unable to verify           | Cần device/live service/catalog/analytics hoặc phép đo chưa thực hiện                       |

“Verified” không bao hàm deploy, asset đang publish, model chất lượng thật hoặc cảm nhận UX. Finding từ code và UX hypothesis được tách riêng.
